# 私人片库：首页、收藏与历史

本页记录用户确认设计后的实际实现，替代旧资源页的固定三栏布局。

## 交互

- `/` 与 `/files` 默认进入 NSFW 片库；电影独立切换，其他格式与分类从「其他资源」进入。传输任务入口改为 `/tasks`。
- 全部页面共用 56px 窄侧栏，切页不切换导航布局；资源页的片库切换、搜索、全部/收藏/历史与隐私开关合并为单行工具栏，手机改为紧凑的两行布局。分类与真实标签各占一条横向快捷行；没有标签时不留空行。
- 格式、分析状态、排序、完整标签搜索、来源目录和刷新放入「筛选与排序」弹层；额外筛选启用时入口显示数量。只有多页结果才显示分页条，不再常驻使用提示和 `1 / 1` 页脚。
- NSFW 与其他资源使用横向封面，电影保留竖向海报；同一列表的卡片等宽等高，标题固定预留两行并维持可读字号，分类/状态固定一行并截断过长内容。完整标题、类别、文件格式和大小可在悬浮简介与详情中读取；悬浮卡独立保留较大的阅读尺寸。
- 分类与细分类常驻首页；标签支持搜索与组合筛选。多个标签必须同时匹配，分类、格式、状态、文字查询与标签共同生效。服务端先筛选后分页，每页 48 项。
- 标签来自已分析资源，不生成装饰性假标签；电影沿用电影分析，NSFW 沿用对应细分类的分析方向。没有证据的内容仍显示待核对。
- 悬停约 320ms 显示大封面、简介、标签与收藏按钮。移入悬浮卡不会关闭；离开约 220ms 后关闭。滚动列表、切换筛选或 Escape 可关闭。键盘与触屏可通过卡片上的信息按钮打开。
- 收藏按钮在卡片、悬浮卡、详情和历史页中共用状态，服务端保存成功后才切换。收藏视图仍支持分类和标签筛选。
- 历史分为「最近打开」与「观看记录」。打开详情才计入打开记录；预加载封面、悬停或只加载播放器元数据都不算观看。实际播放后约每 5 秒保存进度，暂停、关闭播放器、页面隐藏时补存。续播不自动播放。
- 历史可暂停、按条移除、按当前片库及历史类型清空。清空需要确认，覆盖该片库当前类型的全部历史（不只是当前筛选结果），不删除收藏和媒体文件。
- 私人模式遮住封面、标题及悬浮简介；悬浮不会自动解除遮罩，也不会启动媒体加载。它是视觉遮罩，不是加密或新的认证机制。

## 删除资源

- 卡片右侧的垃圾桶在悬停或键盘聚焦时出现，触屏常驻；详情页提供「删除资源」。历史页的「移除记录」仍只删除历史，不能与文件删除混用。隐私遮罩下禁用卡片删除，避免对无法核对的资源误操作。
- 点击后先只读核实，列出当前云盘文件、本地副本以及视频的 `.cover.jpg` 完整路径；勾选确认后才能执行。没有封面或副本会明确标注，不算失败。不递归删除任何目录，不额外处理 Telegram 源消息、其他目录同名资源或旧配置目录中的文件。
- **云盘：**实际删除当前 WebDAV 根目录下的单个资源与对应封面，应用内无法撤销；底层云盘是否有回收站由云盘决定。
- **本地：**移入 `<save_path>/.resource-trash/<操作编号>/<原相对路径>`，字节内容不变，确认和完成弹窗展示恢复位置。回收目录仍占磁盘空间，不自动清空。需要恢复时，先核对原目标不存在，再将相对路径对应文件恢复到下载目录；云端文件和资源索引不会随本地恢复而自动还原。
- 完成后清理资源及封面的索引、收藏、打开/观看记录和对应下载任务记录。目录不会删除，其他资源和历史暂停设置不受影响。全程共用 `module/resource_analysis/deletion.py` 的确认、校验、重试处理，卡片和详情不会各自拼装删除路径。
- 下载、上传或重分析仍在进行（包括待重试）时禁止删除。确认后资源发生变化会停止；本地路径必须在当前下载目录内，目录、符号链接、Windows 联接和编码歧义路径均被拒绝。
- 部分失败逐项显示「已删除 / 已回收 / 不存在 / 尚未完成」，不会把未完成任务报为成功；同一确认可以重试剩余项目。确认凭证绑定当前登录、云盘及本地目录，15 分钟有效，重复提交同一已完成操作不会再次删除。
- 服务端用 `PROPFIND Depth:0` 核实云端目标是文件，再按可用的 ETag/修改时间发送条件删除，禁止跳转并复查删除结果；不会读取视频内容。此流程依赖云盘正确实现 WebDAV 元数据与条件请求。
- 删除标记持久化在资源索引的 PostgreSQL 设置及 `.cache/resource-library/` 本地备份中，本地标记优先于过期数据库索引，防止已删资源被旧下载历史重新展示；备份时应保留该目录。迟到的观看进度和重分析请求不能重建已删除记录。与现有资源索引一样，这适用于单进程部署。
- 接口为 `POST /api/library/delete/preview`（只读生成确认范围）和 `POST /api/library/delete`（使用服务端确认凭证执行），要求登录、JSON、同源请求，响应禁止缓存。确认过期、配置变化、无权限和元数据不明时均停止。

## 封面与性能

在「设置 → 下载规则」开启「下载后自动保存视频封面」（默认开启，对应顶层配置 `generate_video_covers: true`）。完整视频下载到本地、大小校验通过并确定最终分类目录后，独立模块 `module/video_cover.py` 调用 FFprobe/FFmpeg 截取约 10% 处的一帧；无法定位时尝试首帧。该步骤不依赖 AI 分析，也不向分析模型发送截图。

封面为长边不超过 960px 的 JPEG，命名保留完整视频扩展名，例如 `频道/视频.mp4` 对应 `频道/视频.mp4.cover.jpg`，避免 MP4/MKV 同名冲突。生成过程最多同时处理两个视频，带超时与图片校验，使用同目录临时文件和不可覆盖的原子发布。已有有效 JPEG 直接复用；已有无效同名文件也不会覆盖。缺少 FFmpeg、解码失败或磁盘写入失败仅记日志，不影响视频完成。

视频上传成功后再上传封面，保持相同的相对目录。WebDAV 使用独立临时对象、长度校验和 `MOVE Overwrite:F` 发布，不覆盖云端已有封面；rclone/aligo 使用原适配器的忽略/拒绝同名机制。封面不压缩、不加入独立下载记录，且保留本地 JPEG；上传失败不会将已完成的视频标为失败，重试视频任务时可复用本地封面。只有云盘上传会附带封面，不额外发送 Telegram 消息。

首页、收藏、历史与悬浮卡的 `ResourceCover` 只通过现有已认证同源 WebDAV 预览接口读取 `.cover.jpg`，图片资源直接读取图片本身。接近视口或主动查看悬浮卡才加载；请求 URL 包含云盘作用域、视频大小及更新时间的缓存标识，图片使用浏览器私有 HTTP 缓存，不写入 localStorage。隐私遮罩下不发起封面加载。只有显式打开播放器才请求视频；不会为了封面或时长加载视频，卡片时长仅显示已记录的观看元数据。

这项配置作用于之后执行的下载/重试任务，不自动扫描或补处理已有片库。旧视频没有旁侧 JPEG 时显示「暂无已保存封面」，不回退到浏览器截帧。移动或备份视频时应一并保留旁侧 JPEG；关闭开关不删除已经保存的封面。

## 持久化与接口

`module/resource_analysis/activity.py` 独立管理个人记录，不复用下载历史。接口隐藏原子写入、暂停规则、删除范围和完整路径识别；首页、详情和播放器经同一前端写入队列使用它。

- 存储位置：`data/library-activity/<scope-hash>.json`，已排除 Git。该目录是用户数据，不是可随意清理的 `.cache`；备份时应包含它。
- 作用域包括当前 Web 登录 ID、WebDAV 地址、远程根目录和 WebDAV 用户名。切换云盘不会混用收藏或历史。当前应用只有一个 Web 管理员登录，多个浏览器使用同一个管理员时共享记录；这不等于 Telegram 账号之间的独立权限系统。
- 使用进程内锁、临时文件、fsync 和原子替换。写入失败不会在内存中假装保存成功；无法解析已有文件时不会静默覆盖。
- 记录文件是本地明文，依赖主机访问权限。隐私模式不会加密这些文件。当前存储适用于项目现有单进程服务，不能直接用于多个独立写进程。
- `GET /api/library` 新增 `scope`、`view`、`history_kind`、重复的 `tag` 和 `tag_q` 查询参数；返回资源活动状态及标签候选。
- `GET /api/library/activity` 读取记录是否暂停。
- `POST /api/library/activity` 接受 `favorite`、`open`、`progress`、`remove`、`clear`、`pause`。写入需登录、JSON 请求，同源浏览器请求；路径在配置的远程根目录内校验。
- 响应使用 `Cache-Control: private, no-store`。客户端不上传自编简介或任意远程 URL；未索引文件的基本信息由服务端验证后取得。

观看进度以最近一次成功保存为准；强制终止浏览器、断网或主机故障可能丢失最后几秒，失败时界面会提示。暂停记录不影响收藏。

## 验证

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -c "import os, unittest; os.environ['DATABASE_URL'] = ''; unittest.main(module=None)" tests.module.test_resource_deletion tests.module.test_video_cover tests.module.test_cover_upload tests.module.test_library_activity tests.module.test_resource_library tests.module.test_resource_analysis tests.module.test_download_analysis tests.module.test_webdav_preview
node tests/webui/resource_library.browser.cjs
```

在 `webui` 目录运行 `npm run lint`、`npm run build` 及既有三个前端模型测试。

浏览器回归使用本地测试 API、FFmpeg 合成视频及其 JPEG，不访问真实云盘或修改真实收藏/历史；断言浏览、筛选、悬浮、缺失封面与刷新不会读取视频，并覆盖图片解码、封面开关保存与回读、标签交集、收藏/历史、播放与续播、隐私遮罩、异步结果隔离、320–1920px 布局，以及原有任务、设置、账号和登录回归。后端测试覆盖真实合成视频截帧、本地模拟 WebDAV 发布、保留现有文件、非致命错误和下载完整性边界；上述命令显式禁用真实数据库连接。

首屏密度回归会测量第一张资源卡的位置，避免仅通过缩小内容字体满足布局：桌面不超过 180px，手机不超过 245px；另覆盖两条资源、无标签、封面不可用的稀疏片库，以及筛选弹层的状态保留与键盘焦点归还。设置环境变量 `LIBRARY_LAYOUT_ONLY=1` 可只运行这组布局回归。

删除测试仅使用临时目录和模拟 WebDAV，覆盖只读确认、取消、完整路径隔离、目录/链接/越界拒绝、忙碌状态、版本变化、部分失败与重试、回收后字节完整性、旧数据库标记隔离、认证与防跨站请求。浏览器另验证卡片/详情入口、手机布局、确认勾选、执行中防重复、失败结果展示和刷新后的索引/收藏清理，不操作真实用户文件。
