# 媒体工作台 UI 重构

本次替换 React 工作台和管理密码解锁页的结构，不沿用旧版居中仪表盘、自动折叠导航和嵌套卡片布局。现有资源分析、账号认证、任务控制与云盘 API 保持兼容。

## 信息层级

- 全宽工作台包含资源库、传输任务、账号、设置四个入口。全部页面共用固定的 56px 侧栏，点击一次仅切换内容区，不再从侧栏跳回顶部导航；手机端统一使用 42px 紧凑导航。没有固定占位的产品说明，单页资源也不显示分页页脚。
- 资源页已按确认设计更新为私人片库：首页常驻分类和标签、封面网格、交互式悬浮简介、收藏与观看历史，不再默认打开分析侧栏。详情按需打开，正文按内容类别展示。
- 来源目录是次级入口，不暗示移动云端文件。实际封面在可见范围内按需提取，不自动播放；隐私模式不启动提取。完整行为、持久化位置与限制见 [私人片库实现](private-library.md)。
- 任务页突出文件、下载 / 上传进度、失败原因和对应操作。默认每页 15 条，可切换 30 / 60 条；长文件名和错误可展开。删除云端资源与仅删除记录明确分开，重置上传需确认。
- 设置分区保存同一份草稿，有统一保存栏、失败恢复、跨分区校验与离开提醒。服务端确认后才显示保存成功。
- 账号页聚焦身份与运行控制；登录、二步验证、重命名和权限编辑使用统一对话框。破坏性操作有确认，其他会话信息按需展开。

## 行为边界

旧 React 表单中的传输限速、大小 / 日期过滤和自动同步开关没有写入配置 API，本次不再显示为可用设置。旧手动创建任务表单同样没有后端实现，已替换为真实任务来源说明。不要重新加入只改变本地状态的假操作。

解锁页沿用已有加密请求格式，不更改认证机制。登录成功只允许跳转到同源页面。此兼容调整不意味着原有认证机制经过安全审计。

## 验证

在 `webui` 目录运行 `npm run lint`、`npm run build`。在项目根目录运行 `node tests/webui/resource_library.browser.cjs`；它使用离线 API、测试账号与文件，不操作真实 Telegram 会话或云盘资源。

浏览器回归覆盖分类和 NSFW 细分、异步响应隔离、重新分析、详情可读宽度、320–1920px 布局、预览键盘焦点、任务控制与确认、设置保存失败及草稿、验证码 / 二步验证、权限编辑、路由历史、主题记忆和管理密码解锁。生成截图位于忽略版本控制的 `.cache` 目录。

`shell_layout.scenarios.cjs` 另外验证跨行的长短标题卡片等宽等高，以及四个页面切换前后的导航、内容区坐标一致；避免把「最多两行」误当成固定高度，或仅给资源页应用共享导航样式。设置 `LIBRARY_GEOMETRY_ONLY=1` 可只运行这一组回归。
